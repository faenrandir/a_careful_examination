See [About](https://faenrandir.github.io/a_careful_examination/about/)

## Taxonomy

- **Categories** (10, defined in `config.toml`): `book-of-mormon`, `joseph-smith`, `lds-history-leadership`, `doctrine-teachings`, `faith-transitions`, `apologetics-responses`, `research-primary-sources`, `social-moral-issues`, `personal-reflections`, `other`
- **Tags** (70+): see `static/data/tags.json` (canonical) and `static/data/categories.json`

## Site Organization Rules

### "Start Here" Section (Homepage)
Controlled by `templates/index.html:16-46`. Shows pages tagged with `start-here`:
1. **First**: The "peek behind the curtain" article (`path = "/to-peek-behind-the-curtain/"`) — currently `why_examine/why_should_examine_evidence.md`
2. **Then**: Remaining `start-here` pages sorted by `extra.importance` (ascending, lower = more prominent)

Current `start-here` pages (all have `importance = 10` except peek at 11):
- `why_examine/why_should_examine_evidence.md` (peek article, importance 11)
- `truth_claim_summaries/five_key_facts.md`
- `questions/questions.md`
- `book_of_mormon/translation/the_significance_of_the_seer_stone.md`
- `falsehoods_contradictions_and_silliness/you_can_leave_the_church_but_cant_leave_it_alone.md`
- `threefold-nature-of-the-church/retentive_socialization/retentive_socialization_and_indoctrination_in_the_LDS_church.md`

### Homepage Category Cards
Controlled by `templates/index.html:48-77`. For each category in `config.extra.categories`:
- Shows category name, description from config
- Lists first 5 pages in that category (unsorted, first 5 from Zola's page order)
- "View all" link to `/categories/{category-name}/`

### Browse Page (`/browse/`)
Controlled by `templates/browse.html`. Loads taxonomy from `static/data/categories.json` and `static/data/tags.json` (copied to `docs/data/` on build). Renders clickable lists via JS.

### Category Pages (`/categories/{name}/`)
Generated by Zola from `taxonomies` in `config.toml` (categories + tags). Template: `templates/taxonomy_single.html`. Lists all pages in that category.

### Tag Pages (`/tags/{name}/`)
Same as category pages but for tags. Template: `templates/taxonomy_single.html`.

### Frontmatter Fields
- `categories`: Array, maps to config.toml categories (used for category pages)
- `tags`: Array, free-form (used for tag pages + browse page tag cloud)
- `extra.importance`: Integer, lower = more prominent (used in Start Here sort)
- `extra.featured`: Boolean, not currently used in templates
- `path`: Custom URL path (overrides auto-generated permalink)

### Static Data Files
- `static/data/categories.json` — 10 categories with current counts (update manually after re-categorization)
- `static/data/tags.json` — 70+ tags with counts (update manually or regenerate)

## To Build

The site is built with [Zola](https://www.getzola.org/). Make sure `zola` is
installed and in your PATH, then navigate into the root folder of this project.

Preview changes (serves locally with live reload):

    zola serve

Build the site (outputs static files to `docs/`):

    zola build

Release (switches to the release git user, pulls latest, rebuilds, commits,
and pushes):

    python3 scripts/release.py
