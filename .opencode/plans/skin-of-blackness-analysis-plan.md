## 3. Analytical Framework

### 3.1 Per-Passage Rating (1–10 each)
For each of the 7 core passages, assign:
- **Metaphorical Support (M)**: How strongly context favors non-literal reading
- **Literal Support (L)**: How strongly context favors biological pigmentation

### 3.2 Cross-Passage Coherence Tests
| Test | Metaphorical Reading | Literal Reading |
|------|---------------------|-----------------|
| Alma 3:13 (Amlicites self-mark red) | ✅ Mark = paint/garment, self-applied | ❌ How does rebellion change melanin? |
| Jacob 3:8 (Lamanite skins "whiter" at judgment) | ✅ Comparative righteousness | ❌ Nephites by definition "white"; Lamanites can't surpass |
| 3 Nephi 2:15 (Instant "white" upon conversion) | ✅ Spiritual transformation | ❌ No biological mechanism for instant depigmentation |
| 1 Nephi 12:23 / Mormon 5:15 ("dark, filthy, loathsome") | ✅ Triad = spiritual state | ❌ "Filthy" = hygiene? "Loathsome" = appearance? |
| 2 Nephi 30:6 ("scales of darkness" → "white/pure") | ✅ Scales = shedable metaphor | ❌ Scales on eyes ≠ skin |
| Captain Moroni ruse (Alma 55) | ✅ Lamanite needed for language, not appearance | ❌ "White" Nephites with "black" Lamanite = obvious |
| Joseph Smith's 1840 edit (white→pure) | ✅ Prophet clarified metaphor | ❌ Why edit if literal? |
